# いいね機能

[機能一覧](../features.md)へ戻る

## 概要

投稿に対して「いいね」を行う。トグル形式(いいね/取り消し)で、いいね数を投稿に表示する。

## 機能要件

- ログイン済みユーザーは任意の投稿にいいねできる(自分の投稿にも可)
- 同一ユーザーが同一投稿に複数回いいねすることはできない(トグルで取り消し)
- 投稿にいいね数を表示する

## ユースケース

### UC-1: いいね・いいね取り消し
- アクター: ログイン済みユーザー
- 基本フロー:
  1. 投稿のいいねボタンを押下する
  2. 未いいね状態であればLikeレコードを作成し、いいね数を+1する
  3. いいね済み状態であればLikeレコードを削除し、いいね数を-1する

## 関連データモデル

- Like(id, post_id(FK), user_id(FK), created_at)。post_id + user_idでユニーク制約
