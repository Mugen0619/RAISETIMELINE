# プロフィール・フォロー機能

[機能一覧](../features.md)へ戻る

## 概要

ユーザーのプロフィール表示・編集、および他ユーザーのフォロー/フォロー解除を行う。

## 機能要件

### プロフィール
- プロフィール画面には表示名・自己紹介・アイコン・そのユーザーの投稿一覧を表示する
- 自分のプロフィールは表示名・自己紹介・アイコンを編集できる
- 他ユーザーのプロフィールは閲覧のみ(編集不可)、フォロー/フォロー解除ボタンを表示する

### フォロー
- ログイン済みユーザーは他ユーザーをフォロー/フォロー解除できる
- 自分自身をフォローすることはできない
- 同一ユーザーへの重複フォローはできない
- プロフィール画面からフォロー一覧・フォロワー一覧を閲覧できる

## ユースケース

### UC-1: プロフィール編集
- アクター: ログイン済みユーザー(本人)
- 基本フロー:
  1. 自分のプロフィール画面からプロフィール編集画面に遷移する
  2. 表示名・自己紹介・アイコンを編集し、保存する
  3. サーバーがUserレコードを更新する

### UC-2: フォロー / フォロー解除
- アクター: ログイン済みユーザー
- 事前条件: 対象ユーザーが自分自身でないこと
- 基本フロー:
  1. 対象ユーザーのプロフィール画面でフォローボタンを押下する
  2. 未フォロー状態であればFollowレコードを作成する
  3. フォロー済み状態であればFollowレコードを削除する(フォロー解除)

### UC-3: フォロー一覧・フォロワー一覧閲覧
- アクター: ログイン済みユーザー
- 基本フロー:
  1. プロフィール画面からフォロー一覧またはフォロワー一覧を開く
  2. 該当するユーザーの一覧が表示される
  3. 一覧の各ユーザーをクリックするとそのユーザーのプロフィール画面に遷移する

## 関連データモデル

- User(id, username, email, password_hash, display_name, bio, avatar_url, created_at)
- Follow(id, follower_id(FK→User), followee_id(FK→User), created_at)。follower_id + followee_idでユニーク制約
