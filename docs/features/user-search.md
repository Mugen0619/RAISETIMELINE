# ユーザー検索機能

[機能一覧](../features.md)へ戻る

## 概要

ユーザー名・表示名でユーザーを検索する。

## 機能要件

- 検索キーワードによる部分一致検索(ユーザー名・表示名を対象)
- 検索結果一覧から各ユーザーのプロフィール画面に遷移できる
- 検索結果が0件の場合はその旨を表示する

## ユースケース

### UC-1: ユーザー検索
- アクター: ログイン済みユーザー
- 基本フロー:
  1. ユーザー検索画面で検索キーワードを入力する
  2. サーバーがユーザー名・表示名に対する部分一致検索を行う
  3. 検索結果一覧が表示される
  4. 一覧のユーザーをクリックするとそのユーザーのプロフィール画面に遷移する

## 関連データモデル

- User(username, display_name を検索対象とする)
