# 投稿機能

[機能一覧](../features.md)へ戻る

## 概要

テキスト投稿(280文字制限)および画像添付を行う。自分の投稿は編集・削除ができる。

## 機能要件

- 本文は280文字以内(全角・半角問わず文字数でカウント)
- 画像添付(1投稿あたり最大4枚、AWS S3に保存)
- 画像アップロードはS3署名付きURL(presigned URL)方式。クライアントは画像1枚ごとに`POST /api/posts/images/presign`を呼んで署名付きアップロードURLを取得し、S3へ直接PUTしたのち、返却された画像URLを投稿作成/更新APIに渡す
  - `/presign`はサーバー側で署名付きURL発行前に、1枚あたり最大5MB・Content-Typeは`image/jpeg`/`image/png`/`image/webp`のみを許可するバリデーションを行う(1枚単位のチェックであり、投稿あたりの枚数はここでは関知しない)
  - 投稿あたり最大4枚という上限は、投稿作成/更新API(`POST`/`PUT /api/posts`)側で`imageUrls`の件数として検証する。S3へのアップロード自体は`/presign`を呼んだ回数分だけ行われるため、5枚以上presignしてS3にアップロードすることは技術的に可能だが、投稿作成/更新APIが4枚を超える`imageUrls`を拒否する
  - 投稿作成/更新時、渡された画像URLが設定済みS3バケットの公開ベースURL配下であることをサーバー側で検証し、それ以外のURLは拒否する(任意の外部URLを画像として登録できないようにするため)
- 本文のみ・画像のみ・本文+画像のいずれの組み合わせでも投稿可能とする(本文・画像とも空の投稿は不可)
- 投稿者本人のみ編集・削除が可能
- 投稿編集時、画像は全置換(既存のPostImageを削除し、リクエストで渡された画像URLで作り直す)とする
- 削除された投稿はコメント・いいね・画像(PostImage)も合わせて削除する(カスケード削除)
- アバター画像のアップロードは対象外(本機能はあくまで投稿への画像添付のみを扱う)

## ユースケース

### UC-1: 投稿作成
- アクター: ログイン済みユーザー
- 基本フロー:
  1. 投稿作成画面(モーダル)で本文を入力し、必要に応じて画像を添付する
  2. 投稿ボタンを押下する
  3. サーバーが文字数・画像枚数のバリデーションを行い、Post(・PostImage)レコードを作成する
  4. タイムラインに新しい投稿が表示される

### UC-2: 投稿編集
- アクター: 投稿者本人
- 事前条件: 対象投稿の投稿者が操作者本人であること
- 基本フロー:
  1. 投稿詳細画面で編集ボタンを押下し、編集フォーム(投稿作成と共通のモーダル)を開く
  2. 本文を編集し、更新ボタンを押下する
  3. サーバーがバリデーションを行い、Postレコードを更新する

### UC-3: 投稿削除
- アクター: 投稿者本人
- 基本フロー:
  1. タイムライン上の投稿カードまたは投稿詳細画面で削除ボタンを押下する
  2. 確認ダイアログで削除を確定する
  3. サーバーが対象のPost・PostImage・関連するComment・Likeを削除する

## 関連データモデル

- Post(id, user_id(FK), body(≤280文字), created_at, updated_at)
- PostImage(id, post_id(FK), image_url, sort_order)
