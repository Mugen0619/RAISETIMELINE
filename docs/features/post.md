# 投稿機能

[機能一覧](../features.md)へ戻る

## 概要

テキスト投稿(280文字制限)および画像添付を行う。自分の投稿は編集・削除ができる。

## 機能要件

- 本文は280文字以内(全角・半角問わず文字数でカウント)
- 画像添付(1投稿あたり1〜4枚を想定、AWS S3に保存)※上限枚数はTBD、[要件定義書 7. 未決定事項](../requirements.md#7-未決定事項tbd)を参照
- 本文のみ・画像のみ・本文+画像のいずれの組み合わせでも投稿可能とする(本文・画像とも空の投稿は不可)
- 投稿者本人のみ編集・削除が可能
- 削除された投稿はコメント・いいねも合わせて削除する(カスケード削除)

## ユースケース

### UC-1: 投稿作成
- アクター: ログイン済みユーザー
- 基本フロー:
  1. 投稿作成画面(モーダル)で本文を入力し、必要に応じて画像を添付する
  2. 投稿ボタンを押下する
  3. サーバーが文字数・画像枚数のバリデーションを行い、Post(・PostImage)レコードを作成する
  4. タイムラインに新しい投稿が表示される

### UC-2: 投稿編集
- アクター: 投稿者本人
- 事前条件: 対象投稿の投稿者が操作者本人であること
- 基本フロー:
  1. 投稿詳細画面から投稿編集画面へ遷移する
  2. 本文を編集し、更新ボタンを押下する
  3. サーバーがバリデーションを行い、Postレコードを更新する

### UC-3: 投稿削除
- アクター: 投稿者本人
- 基本フロー:
  1. 投稿詳細画面または投稿編集画面から削除を実行する
  2. 確認ダイアログで削除を確定する
  3. サーバーが対象のPost・PostImage・関連するComment・Likeを削除する

## 関連データモデル

- Post(id, user_id(FK), body(≤280文字), created_at, updated_at)
- PostImage(id, post_id(FK), image_url, sort_order)
