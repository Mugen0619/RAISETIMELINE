# 認証機能

[機能一覧](../features.md)へ戻る

## 概要

ユーザー登録・ログイン・ログアウトを行う。認証にはJWT(JSON Web Token)を用いる。

## 機能要件

- メールアドレス・パスワードによる新規ユーザー登録
- ユーザー名・メールアドレスの重複不可
- パスワードはハッシュ化して保存する(平文保存禁止)
- メールアドレス・パスワードによるログイン、成功時にJWTを発行する
- JWTを用いたAPIリクエストの認証(未ログイン状態では投稿・いいね・コメント・フォロー等の操作不可)
- ログアウト(クライアント側のトークン破棄)

## ユースケース

### UC-1: 新規登録
- アクター: 未登録ユーザー
- 事前条件: 対象のメールアドレス・ユーザー名が未使用であること
- 基本フロー:
  1. ユーザー登録画面でユーザー名・メールアドレス・パスワードを入力する
  2. 登録ボタンを押下する
  3. サーバーがバリデーション・重複チェックを行い、Userレコードを作成する
  4. ログイン状態でタイムライン画面に遷移する
- 代替フロー: ユーザー名・メールアドレスが重複している場合はエラーを表示する

### UC-2: ログイン
- アクター: 登録済みユーザー
- 基本フロー:
  1. ログイン画面でメールアドレス・パスワードを入力する
  2. サーバーが認証情報を検証し、JWTを発行する
  3. タイムライン画面に遷移する
- 代替フロー: 認証情報が誤っている場合はエラーを表示する

## 関連データモデル

- User(id, username, email, password_hash, display_name, bio, avatar_url, created_at)
