# タイムライン機能

[機能一覧](../features.md)へ戻る

## 概要

投稿を一覧表示する。「全体」と「フォロー中」の2つのタブを切り替えて閲覧できる。

## 機能要件

- 全体タイムライン: 全ユーザーの投稿を新着順に表示する
- フォロー中タイムライン: 自分がフォローしているユーザーの投稿のみを新着順に表示する
- 投稿一覧は無限スクロールまたはページネーションで取得する(実装フェーズで方式を決定)
- 各投稿にはいいね数・コメント数を表示する(インプレッション数は表示しない)

## ユースケース

### UC-1: タイムライン閲覧
- アクター: ログイン済みユーザー
- 基本フロー:
  1. タイムライン画面にアクセスする(デフォルトは全体タブ)
  2. 投稿一覧が新着順に表示される
  3. 「フォロー中」タブに切り替えると、フォロー中ユーザーの投稿のみに絞り込まれる
  4. スクロールまたはページ送りで過去の投稿を追加取得する

## 関連データモデル

- Post、PostImage、Like、Comment(件数集計)、Follow(フォロー中タブの絞り込み条件)
