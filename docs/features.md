# 機能一覧・ユースケース

[要件定義書](./requirements.md)の機能一覧に対応する各機能の定義書へのインデックス。詳細な機能要件・ユースケースは各リンク先を参照。

| 機能 | 概要 | 詳細 |
|---|---|---|
| 認証 | ユーザー登録・ログイン(JWT)・ログアウト | [features/authentication.md](./features/authentication.md) |
| 投稿 | テキスト投稿(280文字制限)・画像添付・編集・削除 | [features/post.md](./features/post.md) |
| タイムライン | 全体/フォロー中タブ切替での投稿一覧表示 | [features/timeline.md](./features/timeline.md) |
| コメント | 投稿へのコメント・削除・コメント数表示 | [features/comment.md](./features/comment.md) |
| いいね | 投稿へのいいねトグル・いいね数表示 | [features/like.md](./features/like.md) |
| プロフィール・フォロー | プロフィール表示・編集、フォロー/フォロー解除、フォロー・フォロワー一覧 | [features/profile.md](./features/profile.md) |
| ユーザー検索 | ユーザー名・表示名によるユーザー検索 | [features/user-search.md](./features/user-search.md) |

画面構成・遷移は[screen-design.md](./screen-design.md)を参照。
